# Review 2026-11-07 — accessibility, layout and performance (outside the Protocols tab)

Owner instruction: "skip the protocols section, but perfect the rest". The Protocols tab was not reviewed or changed; every fix below is scoped away from it, and the Protocols source lock, the Example Protocols snapshot and the rendered locks (desktop and phone) are the guard.

## Method

Read-only auditors worked against a built copy of 7.10.4 in headless Chromium 141 with synthetic entries only:

- **Accessibility (WCAG 2.2 AA):** axe-core 4.11.0 on 34 states × 390×844 and 1440×900 × light and dark (136 scans), plus keyboard traversal (5,218 Tab stops), reflow at 320 px, 200–400% zoom approximated with CSS-pixel viewports, text spacing, target size, reduced motion and forced colors.
- **Layout and interaction:** 690 states at 360, 390, 768, 1024, 1280 and 1440 px in both themes (about 1,300 screenshots; about 70 inspected by eye, the rest by automated probes for overflow, clipping, CLS and contrast).
- **Performance:** an esbuild metafile with the production options, 4× CPU-throttled runtime traces at 390×844, and Lighthouse 12.8.2 (desktop 98, mobile 69 on an uncompressed local server; accessibility, best practices and SEO 100).

Not completed in this round (stopped at the owner's deadline): clinical-logic boundary testing, offline/PWA behaviour, evidence currency since 2026-10-31, the trial-registry recheck, CI and dependency hygiene, and a copy and link sweep.

## Fixed in 7.11.0

| Finding | Fix |
|---|---|
| Trials: "View N possible candidates" (below 1024 px) opened the Retired destination page, because `#trial-results` was read as a route | In-page button that scrolls to the results and focuses the result summary |
| Short screens (≤ 440 px tall): header, case bar and docked nav covered 62–100% of the screen; focus hidden (1.4.10, 2.4.11) | Header and case bar scroll with the page at ≤ 440 px tall on every surface except Protocols |
| Case bar offered the thrombolytic "Dose table" in ICH, SAH, TIA and other encounters | Shown only for acute ischemic stroke, a recorded administration, or before a diagnosis is chosen |
| More panel stayed open over the focused control; a press in the install sheet closed it; Escape always moved focus to More | Closes when focus leaves it (dialogs it opened excepted); Escape returns focus only from inside |
| Global search field: no focus indicator (2.4.7); placeholder 2.54:1 (1.4.3) | Focus ring on the field; placeholder uses the muted token (passes in both themes) |
| Forced colors erased selected, pressed and current states, link markers and the Copy button boundary | `@media (forced-colors: active)` rules scoped to Encounter, Trials, the nav and the wide indexes |
| Trial-criteria dialog: Close scrolled out of view on phones | Sticky title row with Close |
| Evidence search: 79–154 ms long task per keystroke at 4× throttling | Per-record memoization; identical results for 2,061 queries × 4 settings; 229 → 2.5 ms per typed word unthrottled |
| Registry links showed two arrow markers; database search name did not start with its visible label (2.5.3) | One CSS marker (also in the dialog); label-first accessible name |
| Wide Evidence index headings ran into their counts ("ACUTE ISCHEMIC STROKE19") | Count set apart, spoken as ", 19 topics" |
| Evidence and Calculators failure states unstyled; reference tiles teal in dark mode; checklist selects misaligned at 481–768 px | Styled like the retired-page card (Protocols fallback unchanged); tiles keep ink; alignment from 481 px |
| qa-smoke compared `--case-bar-h` before the ResizeObserver could run | Waits for a rendering opportunity (fails after 2 s if still stale) |
