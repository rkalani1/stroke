# Bounded clinical statement trace

`src/clinical/claims.json` and its registry retain existing shared dose and prognosis-safety statements. Original clinical review dates remain unchanged. The bounded evidence graph, six maintained source projections and protected literal exceptions support the surviving workspace. No individualized prognosis output is enabled.

`docs/clinical-claim-occurrences.json` maps four rule groups. Active occurrences preserve their exact excerpts/fingerprints and canonical, excluded or manual-review dispositions. Removed occurrences/PDF exports retain explicit archival provenance; their absence is checked against the retirement inventory rather than silently resetting fingerprints. Protected protocol text and the Telestroke map stay outside deduplication and retain independent locks.

Run `npm run check:clinical-claims`, citation/evidence/content validators and protocol snapshots after changes. The trace fails on an unexplained active occurrence/source change or invalid retirement. Review each affected consumer and primary source before changing fingerprints. Never blanket-regenerate protected baselines or use a passing snapshot as clinical validation. PDF generators and the broad seeded corpus are retired, preserved only at `archive/pre-encounter-first-20261001-4f8e99d`.

`docs/maintained-source-projections.json` records exact source selections and original review/correction provenance. `docs/source-limits.md` identifies unresolved corrections/access limits and the resolved, owner-authorized protected ICH factor-Xa correction. Build/archival timestamps do not refresh clinical review dates. Arithmetic changes require independent expected-value tests and authoritative applicable source/label review; recommendation changes require population, missing-data and safety review as well.
