# Evidence ledger — 7.9.0 review (accessed 2026-10-21 and 2026-10-22)

One row per clinical claim, registry profile, scoring definition or behaviour that this review verified, corrected, added, flagged or left unresolved. Column order: claim / feature · location · status · source (title, URL/DOI/PMID/NCT, publication date) · access date and scope · supporting passage · limitations / resolution. Each unit's full report, with findings and its own tests, is in [review-2026-10-21/](review-2026-10-21/). The previous ledger for 7.8.0 is [evidence-ledger-2026-10.md](evidence-ledger-2026-10.md).

**Access limits that apply throughout.** The review container's network policy blocked publisher sites (ahajournals.org, nejm.org, thelancet.com), PMC web pages, DailyMed, FDA pages and github.io. Sources were read through the PubMed connector (abstracts and PMC full text), the ClinicalTrials.gov connector (full registry records) and web search (secondary summaries, never the sole basis for a change). The 2026 AHA/ASA AIS guideline (PMID 41582814) full text was not reachable; its recommendations were compared with the app's archived transcription (`git show 4f8e99d:data/guidelines/ais-2026.json`), which is marked "archive scope" and is secondary. Drug-label facts were confirmed only from secondary copies (for example an editorial reproducing the tenecteplase label). `checkedAt` dates were changed only for sources actually re-read on 2026-10-21; the access field says what was read.

**Verification.** Each unit verified its own claims against primary sources. The lead then checked the highest-risk changes against the same sources, and three independent verification rounds re-read the primary sources and the shipped code (results in [the verification section](#independent-verification) below; the resulting corrections are in [Verification-round corrections](#verification-round-corrections-2026-10-22)). Passing tests do not establish clinical validity, and source checks do not establish software correctness; both were required.
