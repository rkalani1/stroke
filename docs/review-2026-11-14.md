## Decisions and judgement calls

- **Case-bar BP flag:**
  - With IVT not recommended and EVT undecided, the pre-EVT limit (>185/110) applies, so the bar does not under-flag while EVT is still possible.
  - A reperfusion time or mTICI recorded without a puncture time counts as a procedure; the 24 h window then runs from reperfusion.
  - 24 h after a recorded puncture, no BP flag is shown.
  - After IVT, the stricter post-IVT limit applies even if EVT follows.
- **"/" shortcut:** removed app-wide, because a single-character shortcut that cannot be turned off fails WCAG 2.1.4. Ctrl/⌘K opens search.
- **Install verification:** a failed digest check leaves the running version and its cache untouched; the next update check retries. This makes the build's integrity load-bearing. Anything that edits a precached file after `npm run build` without rebuilding blocks every install. `check-committed-bundle`, the coherence tests and qa-smoke's fresh-install check catch this.
- **Precache ceiling:** kept at 2.3 MB (79% used) as headroom, as the 2026-10-21 review proposed.
- **JavaScript ceilings:** raised by about 2%. The reason is recorded in `scripts/check-asset-budget.mjs`.
- **Owner-pinned decisions left as they are:**
  - The workspace description (it keeps "Pulsara summaries and Epic note templates").
  - The light launch colors (PWA-05).
  - The "65 year old" wording and the Epic note headings (copy-06).

## Deferred

- **PWA-03 (shared origin):** other pages on `rkalani1.github.io` can write to this origin's caches and post messages to the page. Checking the message source would protect only against a compromised sibling site, and would need synthetic-message tests. It was judged not worth its code.
- **PWA-04 (Content-Security-Policy):** a strict hash-based policy produced zero violations in the audit. But a meta CSP governs the whole document, the Protocols page included, so it is left for an owner decision.
- **PWA-05 (iOS launch images):** several current iOS devices have no matching launch image. Adding images enlarges the precache-free runtime set and needs a device check.
- **PWA-07 (robots):** `/stroke/robots.txt` is never read by crawlers, because robots files are read only at the origin root. That is informational and cannot be fixed from this repository.
- **copy-05 (Encounter part)** and **copy-07 (mRS terms):** there are three mRS descriptor wordings and five names across Encounter, notes, screens and Calculators. Unifying them touches note output and the Calculators descriptors and needs one agreed wording.
- **ENG-7 and ENG-8:** dead exports and unwired one-shot scripts. None of them ships (all are tree-shaken or outside the public artifact).
- **Remaining npm advisories:** six in the root tree and one in `mcp/`. All need major upgrades of development tooling (vitest 2 → 5, esbuild 0.24 → 0.25+, zod 3 → 4 for the repository-local MCP server). None ships to Pages.
- **Trials error strings:** a few still use hyphen ranges ("LKW-to-randomization not 14-180 days"), while the matched labels now use en dashes.
- **Line endings:** there is no `.gitattributes`. A Windows checkout with `core.autocrlf` would hash CRLF bytes and fail `check-committed-bundle` locally. The served bytes are unaffected.
