# Evidence ledger — 7.8.0 review (accessed 2026-10-17)

One row per clinical claim, registry profile or scoring definition that this review verified, corrected, added or flagged. Columns: claim / feature · location · status · source (title, URL/DOI/PMID/NCT, publication date) · access date and scope · supporting passage · limitations / resolution.

Access limits that apply throughout: this review ran in a container whose network policy blocked publisher sites (ahajournals.org, nejm.org), PMC web pages, DailyMed and FDA labels. Sources were read through the PubMed connector (abstracts and PMC full text), the ClinicalTrials.gov connector (full registry records) and web search (secondary summaries, never used alone for a change). Where a row says "archived transcription", the comparison is internal consistency with the app's earlier full-text extraction, not a fresh read of the guideline. Each unit's claims were re-checked by an independent reviewer agent against the same primary sources before merge.

Not shipped in 7.8.0: the EVT/systems and prevention/rehabilitation evidence units finished implementation but not independent review before the release deadline; their findings and draft ledger rows are kept for a follow-up and are not included here.
